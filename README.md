# ReR Coin (RERC)

An independent digital currency protocol built on Roman numeral logic.

**Mine. Decipher. Conquer.**

---

## What is ReR Coin?

ReR Coin is a peer-to-peer digital currency with real proof-of-work mining,
cryptographic wallets, and a distributed network. The mining challenge is
based on classical Roman numeral logic — a structural divergence from
conventional decimal-based blockchains.

## How to Mine

1. Download the installer from the Releases section
2. Install and open — mining starts automatically
3. Your wallet is generated on first launch
4. Mine RERC and generate your official wallet voucher (PDF)
